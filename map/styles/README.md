# Styles MapLibre

Le style `real-map-v1.json` porte les couches cadastrales internes :

- parcelles à partir du zoom 13 ;
- bâtiments à partir du zoom 15 ;
- sélection conservée par filtre d'identifiant côté MapLibre ;
- attribution Etalab / DGFiP dans la carte.

Le fond clair et l’orthophoto IGN sont ajoutés à la demande dans le client afin que l’orthophoto ne soit jamais téléchargée tant que l’utilisateur ne l’a pas activée.
