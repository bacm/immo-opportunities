# v0.2 — Cadastre 35

**État :** Terminée  
**Dépend de :** v0.1

## Objectif utilisateur

Obtenir la première donnée immobilière réelle, reproductible et auditable : les parcelles et emprises cadastrales d’Ille-et-Vilaine.

## Inclus

- contrat de source DS-01 Cadastre Etalab/PCI ;
- téléchargement versionné et reprise sur erreur ;
- stockage brut immuable dans MinIO ;
- `DataSource`, `DatasetRelease`, `RawAsset`, `ImportRun`, `TransformationRun` et `DataQualityCheck` ;
- import partitionné d’abord sur un petit échantillon, puis sur le département 35 ;
- normalisation en Lambert-93 ;
- parcelles, bâtiments cadastraux et références administratives ;
- contrôles de géométrie, schéma, doublons et couverture ;
- rapport d’acceptation `accepté / affichage seulement / rejeté`.

L’échantillon de développement contient au minimum une commune urbaine, périurbaine et rurale. Le pipeline final reste partitionné par département et release.

## Hors périmètre

- rapprochement avec BAN, RNB ou BDNB ;
- score d’opportunité ;
- interprétation de l’usage des bâtiments ;
- publication de toute la Bretagne.

## Données et transformations

- enregistrer URL, producteur, licence, millésime et checksum ;
- conserver le fichier source sans modification ;
- vérifier le SRID et transformer vers EPSG:2154 si nécessaire ;
- réparer uniquement les géométries réparables selon une transformation versionnée ;
- mettre les géométries invalides en quarantaine ;
- distinguer les bâtiments cadastraux des futurs bâtiments résolus ;
- mesurer couverture, nullité, doublons et anomalies par commune.

## Tests obligatoires

- contrat testé sur un fichier réel et un fixture minimal ;
- checksum incorrect détecté ;
- changement de schéma détecté ;
- relance idempotente sans doublon ;
- géométrie invalide mise en quarantaine ;
- rollback d’une release non publiée ;
- comparaison de deux imports ;
- vérification d’un échantillon visuel de communes.

## Critères d’acceptation

- chaque ligne normalisée remonte à un `RawAsset` ;
- les métriques existent pour toutes les communes du 35 ;
- les écarts entre compte source et compte publié sont expliqués ;
- les requêtes spatiales élémentaires utilisent un index GiST ;
- une release n’est visible qu’après publication atomique ;
- le rapport DS-01 conclut explicitement sur les usages autorisés.

## Démonstration attendue

Lancer l’import du département 35, consulter son exécution dans Dagster, ouvrir le rapport qualité, puis interroger une parcelle réelle et sa provenance.

## Risques

- confondre bâtiment cadastral et bâtiment physique ;
- réparer silencieusement des géométries ;
- charger directement les fichiers bruts dans les tables publiées ;
- lier le pipeline à un millésime unique.

## Definition of Done

- [x] Contrat DS-01 versionné.
- [x] Fichiers bruts et checksums conservés.
- [x] Import départemental idempotent.
- [x] Quarantaine et métriques disponibles.
- [x] Rapport d’acceptation DS-01 produit.
- [x] Provenance vérifiable jusqu’à la ligne source.
- [x] Performance et volumétrie documentées.

## Exploitation locale

Dans Dagster, ajouter les clés dynamiques `2026-06-01` à `cadastre_releases` et `35` à
`departments`, puis matérialiser `cadastre_department_release` pour la partition correspondante.
Cette exécution télécharge environ 244 MiB compressés pour les couches communes, parcelles et
bâtiments, archive chaque fichier dans MinIO, importe une release invisible et produit le rapport
qualité.

La publication est volontairement séparée :

```bash
docker compose --env-file .env.example \
  -f compose.yaml -f compose.dev.yaml -f compose.observability.yaml run --rm \
  dagster-code python pipelines/scripts/cadastre_release.py report DS-01@2026-06-01

docker compose --env-file .env.example \
  -f compose.yaml -f compose.dev.yaml -f compose.observability.yaml run --rm \
  dagster-code python pipelines/scripts/cadastre_release.py accept \
  DS-01@2026-06-01 --mode accepted

docker compose --env-file .env.example \
  -f compose.yaml -f compose.dev.yaml -f compose.observability.yaml run --rm \
  dagster-code python pipelines/scripts/cadastre_release.py publish \
  DS-01@2026-06-01 --department 35 --actor local-admin \
  --reason "Contrôles DS-01 validés"
```
