# v0.4 — Carte réelle

**État :** Bloquée — démonstration adresse dépendante de DS-05  
**Dépend de :** v0.3

## Objectif utilisateur

Explorer de vraies parcelles et de vrais bâtiments sur une carte performante, puis ouvrir leur fiche sans perdre le contexte géographique.

## Inclus

- Martin connecté à PostGIS avec le rôle `tiles_ro` ;
- fonctions MVT versionnées pour parcelles et bâtiments ;
- géométries de rendu séparées des géométries d’analyse ;
- MapLibre et `react-map-gl/maplibre` dans le frontend ;
- fond clair et orthophoto autorisée à la demande ;
- recherche adresse/commune/parcelle ;
- sélection et emprise conservées dans l’URL ;
- liste exacte chargée par API pour l’emprise visible ;
- états chargement, vide, hors couverture, données partielles et erreur récupérable ;
- attribution des producteurs.

La carte SVG et les candidats simulés actuels restent disponibles uniquement comme fixtures de développement jusqu’à leur suppression en v0.7.

## Hors périmètre

- score métier complet ;
- couches privées mises en cache publiquement ;
- chargement d’un GeoJSON régional ;
- collaboration ou alertes.

## API et tuiles

- `GET /api/v1/areas`
- `GET /api/v1/search`
- `GET /api/v1/parcels/{id}`
- `GET /api/v1/buildings/{id}`
- `GET /api/v1/property-units/{id}`
- `/tiles/v1/parcels/{z}/{x}/{y}.mvt`
- `/tiles/v1/buildings/{z}/{x}/{y}.mvt`

Les tuiles contiennent seulement les attributs nécessaires au rendu. Le détail est obtenu par l’API.

## Tests obligatoires

- contrat OpenAPI et client TypeScript généré ;
- navigation clavier de la recherche et de la liste ;
- synchronisation URL, carte, liste et fiche ;
- absence de téléchargement GeoJSON départemental ;
- permissions du rôle Martin ;
- p95 des tuiles chaudes et froides mesuré ;
- test Playwright du parcours recherche → sélection → fiche ;
- vérification des attributions et des niveaux de zoom.

## Critères d’acceptation

- une recherche réelle recentre la carte sur la bonne entité ;
- la liste correspond à l’emprise et aux filtres géographiques ;
- une sélection survit au rechargement de la page ;
- Martin ne peut lire ni `app`, ni `audit`, ni les tables sources ;
- les objectifs de performance NFR applicables sont mesurés ;
- une zone non couverte est distinguée d’une zone sans résultat.

## Démonstration attendue

Rechercher une adresse du 35, afficher la parcelle et les bâtiments par MVT, déplacer la carte, actualiser la liste et partager l’URL sélectionnée.

## Risques

- faire transiter les tuiles par FastAPI ;
- exposer trop d’attributs dans les MVT ;
- mettre des données privées dans une tuile commune ;
- optimiser avant d’avoir mesuré les requêtes.
